# Assets

| Folder | What is in it |
| --- | --- |
| `assets/brand/` | The Strands of Grace logo in web sizes, the lotus on its own, `emblem.webp` (the home page emblem, a stand-in until the celestial woman arrives: replace this one file), icons and the share image. See `BRAND.md` for which file goes where. |
| `assets/portraits/` | Lisa's portrait. `lisa-hero.jpg` (2000 px) and `lisa-hero-1200.jpg` are the beach photo; `lisa-hero-arch.jpg` (740 x 1028) and `lisa-hero-arch-480.jpg` are its crop for the arch on the home page; `lisa-portrait.jpg` is a close 4:5 crop of it. |
| `assets/source/` | Original uploads, untouched, kept for reference. Excluded from every deploy by `.vercelignore`. Never link to them from the site. |

To add a photo, export a copy no wider than 2000 px as a JPEG (or WebP), put it
in `assets/portraits/` and reference it from the page.
